# Attachments

You can attach files, such as documents, spreadsheets or instrument output, to an Experiment so that everything related to the work is kept in one place.

## Before you start

- Open the Experiment you want to work with. See [Projects, Notebooks and Experiments](02-projects-notebooks-experiments.md).
- Limits: a file can be up to **30 MB**, and an Experiment can have up to **100** attachments.
- Deleting a file requires **Can Edit** permission or higher. See [Permissions and Team Management](07-access-and-permissions.md).

---

## How to view attachments

Open the **Attachments** section of the Experiment. It is expanded by default and keeps the state you left it in. Each file shows its type icon, name, uploader, size and upload date and time.

## How to attach a file

1. In the **Attachments** section, click **Attach File**.
2. Select a file in the dialog.

The file is added to the list. If it is rejected, you see "File *file name* is too large. Max size is 30MB." or "Attachment limit exceeded (100 max). Please delete unnecessary files."

## How to download or delete a file

1. Click the three dots (**More options**) next to the file.
2. Select **Download** or **Delete**.

> Tip: **Delete** is shown only to members with **Can Edit** permission or higher.
