# Glossary

| Term | Meaning |
|---|---|
| **Project** | Top level of the hierarchy. Contains Notebooks. |
| **Notebook** | Sits inside a Project. Contains Experiments. |
| **Experiment** | A single piece of lab work, with description, reaction, stoichiometry, batches and attachments. |
| **Member / Team** | The users who have access to a Project, Notebook or Experiment, each with a permission level. |
| **Limited View** | A permission the system gives automatically on a parent item to someone added only to a lower-level item. They see only the items they were added to. See [Permissions and Team Management](07-access-and-permissions.md). |
| **Template** | A predefined layout for an Experiment. See [Administration](08-administration.md). |
| **Dictionary** | A managed list of words used in drop-down fields. Each entry is a word. |
| **Dictionary editor permission** | Required to open and edit Dictionaries. |
| **Starred Experiment** | An Experiment you marked for quick access. |
| **My Entities** | A filter on the Dashboard that shows only items you created. |
| **Reaction schema** | The drawn chemical reaction of an Experiment. |
| **Stoichiometry table** | Tables of Reactants, Reagents, Solvents and Products with amounts and calculated values. |
| **Limiting material** | The reactant that determines the maximum amount of product. |
| **Intended Reaction Product** | The product the reaction is meant to produce. |
| **Side Product** | A product formed in addition to the intended one. |
| **Equivalents (EQ)** | The amount of a material relative to the limiting material. |
| **Salt Code / Salt EQ** | The salt form of a compound and its equivalents. |
| **Stereoisomer Code** | The stereochemical form of a compound. |
| **My Materials** | Your personal list of frequently used materials. |
| **Batch** | A prepared portion of a product from an Experiment. |
| **Registration / Registered Batch Number** | Formally recording a batch; the number it receives. |
| **Batch Creator** | The person who created a batch. |
| **Sample** | A material linked to a stoichiometry row. |
| **Analytical Sample** | A sample sent for analysis. See [Batches and Analytics](05-batches-and-analytics.md). |
