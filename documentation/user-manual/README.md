# Indigo ELN User Manual

This manual explains how to use Indigo ELN for everyday work and for administration. It is organized by task: find the job you want to do and follow the numbered steps.

## Who should read what

- **Chemists and other lab users:** chapters 1 to 6.
- **Project leads:** chapters 2 and 7 (managing team members and permissions).
- **Administrators:** chapter 8 (templates, dictionaries).

## Contents

1. [Getting Started](01-getting-started.md): log in, Dashboard, navigation, Global Search
2. [Projects, Notebooks and Experiments](02-projects-notebooks-experiments.md): how work is organized, creating and editing each level, team members
3. [Working in an Experiment](03-working-in-an-experiment.md): description, details, completing an Experiment
4. [Reaction and Stoichiometry](04-reaction-and-stoichiometry.md): drawing the reaction, working with the stoichiometry tables
5. [Batches and Analytics](05-batches-and-analytics.md): registering batches, sample analytics
6. [Attachments](06-attachments.md): adding and downloading files
7. [Permissions and Team Management](07-access-and-permissions.md): adding members, permission levels, inherited access
8. [Administration](08-administration.md): templates and dictionaries

Appendix: [Glossary](appendix-glossary.md)

## Conventions

- **Bold** text is a button, tab, field or menu item exactly as it appears on screen.
- A "Tip" gives a shortcut or a heads-up.
- Features that are planned but not yet released are not described in the instructions. A note marked **Not yet available** appears next to the related feature.
